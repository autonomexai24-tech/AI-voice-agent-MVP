# Core Product Philosophy

The platform is NOT:
- a chatbot
- a generic AI assistant
- an autonomous agent framework
- a text-generation playground

The platform IS:
- a realtime conversational runtime
- a multilingual AI receptionist system
- a deterministic orchestration engine
- a low-latency voice infrastructure platform

The primary product goal is:

> “The receptionist sounded real.”

All engineering decisions should optimize for:
- conversational realism
- responsiveness
- reliability
- low hallucination behavior
- operational simplicity
